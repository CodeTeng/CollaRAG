- **w/o Dual-Path**：移除规则兜底后 EM 下降 ~2%，双路径提供鲁棒性保障

## 经验记忆增长曲线（骨干模型：Qwen3-32B，HotpotQA）

| 查询窗口 | EM | F1 |
|---|---|---|
| 1–50 (冷启动) | 0.449 | 0.601 |
| 51–100 | 0.481 | 0.635 |
| 101–200 | 0.496 | 0.651 |
| 201–300 | 0.511 | 0.670 |
| 301–400 | 0.526 | 0.682 |
| 401–500 | 0.534 | 0.691 |

**关键发现：**

- 冷启动阶段（1–50）EM=0.449，经验记忆尚未积累
- 51–100 查询后 EM 快速提升至 0.481（+7.1%），经验开始发挥作用
- 300 查询后增速放缓，趋于饱和，最终 EM=0.534（相比冷启动 +18.9%）
- F1 呈现相似趋势，从 0.601 提升至 0.691（+15.0%）
- 验证了经验记忆的飞轮效应：正反馈循环使性能随查询积累持续提升
