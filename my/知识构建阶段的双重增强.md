## 🎯 设计目标

### 现状分析

#### 传统RAG知识构建的问题

| 问题           | 现象                      | 影响                         |
| -------------- | ------------------------- | ---------------------------- |
| **固定分块**   | 所有文档/段落用同一块大小 | 语义割裂或信息冗余           |
| **提取不充分** | 仅提取显式关系            | 遗漏深层语义，知识图谱不完整 |
| **冗余过多**   | 同义三元组重复            | 图规模膨胀，查询噪声增加     |
| **无自适应**   | 无法应对不同领域/难度     | 跨领域泛化能力差             |

#### Youtu-GraphRAG中存在的具体问题

1. **`kt_gen.py` 的固定分块**：

   ```python
   # 现有代码（固定窗口）
   if split_by == "sentence":
       chunks = sentences
   elif split_by == "size":
       # 所有文档用相同的chunk_size参数（如512）
       chunks = [' '.join(sentences[i:i+window_size])
                for i in range(0, len(sentences), step)]
   ```

   - 无法适应不同复杂度的内容

2. **`agentic_decomposer.py` 和 LLM 的三元组提取**：
   - 仅使用单轮LLM调用提取显式关系
   - 缺少隐式关系、因果关系、时序关系的提取
   - 没有Schema引导的补全

3. **缺乏冗余控制**：
   - "北京位于中国" 和 "北京在中国" 都会作为独立三元组存储
   - 传递关系（A→B, B→C, A→C）都被保留

### 解决方案

DEKER框架通过**三层递进式增强**解决以上问题：

```
┌─────────────────────────────────────────────────────┐
│     第1层：动态粒度调整 (Dynamic Granularity)       │
│  根据内容复杂度 + 实体密度自动调整分块大小           │
└────────────────────┬────────────────────────────────┘
                     ▼
┌─────────────────────────────────────────────────────┐
│     第2层：分层三元组提取 (Layered Extraction)      │
│  - 显式关系 (explicit)                              │
│  - 隐式关系 (implicit)                              │
│  - Schema引导 (schema-guided)                       │
│  - 跨句关系 (cross-sentence)                        │
└────────────────────┬────────────────────────────────┘
                     ▼
┌─────────────────────────────────────────────────────┐
│     第3层：双重冗余剪枝 (Dual-Redundancy Pruning)   │
│  - 相似度冗余去除 (similarity-based)                │
│  - 传递性冗余去除 (transitivity-based)              │
└─────────────────────────────────────────────────────┘
```

## 🔧 核心模块详细设计

### 模块1：动态粒度调整器 (Dynamic Granularity Adjuster)

#### 功能说明

根据**文本内容特征**动态调整分块大小，确保：

- ✅ 语义完整性（不割裂重要单元）
- ✅ 冗余控制（避免过量重叠）
- ✅ 跨领域适应（自动适应不同领域）

#### 关键指标

**1. 内容复杂度 (Content Complexity)**

```python
def calculate_content_complexity(text: str) -> float:
    """
    计算文本复杂度 (0-1)

    组成：
    - 句法复杂度 (syntax_complexity): 平均依存距离
    - 词汇多样性 (lexical_diversity): TTR (Type-Token Ratio)
    - 句长方差 (length_variance): 句长标准差

    公式：
    complexity = (syntax + ttr + variance) / 3
    """
```

| 复杂度范围 | 文本特征 | 推荐块大小    | 例子               |
| ---------- | -------- | ------------- | ------------------ |
| 0.0-0.3    | 简单直白 | 大（400-500） | 新闻摘要、列表     |
| 0.3-0.6    | 中等复杂 | 中（250-350） | 普通文章、说明文   |
| 0.6-1.0    | 高度复杂 | 小（100-200） | 学术论文、法律文件 |

**2. 实体密度 (Entity Density)**

```python
def calculate_entity_density(text: str) -> float:
    """
    计算命名实体的密度 (0-1)

    定义：
    density = (entity_count / token_count) * 100

    密度越高 → 实体关系越密集 → 块应该更小
    """
```

| 密度范围 | 含义   | 块大小调整 | 例子           |
| -------- | ------ | ---------- | -------------- |
| 0.0-0.1  | 低密度 | ↑ 增大     | 叙述文、故事   |
| 0.1-0.3  | 中密度 | → 保持     | 普通新闻、评论 |
| 0.3+     | 高密度 | ↓ 减小     | 新闻简报、表格 |

#### 自适应编码

```python
class DynamicGranularityAdjuster:
    """动态粒度调整器"""

    def __init__(self,
                 min_size=100,         # tokens
                 max_size=500,         # tokens
                 base_size=300,        # tokens
                 complexity_weight=0.4,
                 density_weight=0.6):
        self.min_size = min_size
        self.max_size = max_size
        self.base_size = base_size
        self.c_weight = complexity_weight
        self.d_weight = density_weight
        self.nlp = spacy.load("en_core_web_sm")

    def adjust_chunk_size(self, text: str) -> int:
        """计算最优块大小"""
        # 计算两个指标
        complexity = self.calc_complexity(text)
        density = self.calc_entity_density(text)

        # 加权综合（两个指标权重和为1）
        combined_score = (self.c_weight * complexity +
                         self.d_weight * density)

        # 反向映射：score高 → 块小
        # score=0.0 → size=max_size
        # score=1.0 → size=min_size
        epsilon = 0.05
        adjusted_size = int(
            self.base_size -
            (combined_score - 0.5) * (self.base_size - self.min_size) * 2
        )

        # 限制在范围内
        return max(self.min_size, min(self.max_size, adjusted_size))

    def chunk_document(self, doc: str, doc_id: str) -> List[Dict]:
        """对文档进行自适应分块"""
        sentences = self._split_sentences(doc)
        chunks = []
        current_chunk_sents = []
        current_tokens = 0
        target_size = None

        for sent in sentences:
            sent_tokens = len(self.tokenizer.encode(sent))

            # 在块开始时计算目标大小
            if not current_chunk_sents:
                target_size = self.adjust_chunk_size(sent)

            # 如果加入此句超过目标，且块非空
            if current_tokens + sent_tokens > target_size and current_chunk_sents:
                # 保存当前块
                chunk_text = " ".join(current_chunk_sents)
                chunks.append({
                    "text": chunk_text,
                    "chunk_id": f"{doc_id}_chunk_{len(chunks)}",
                    "doc_id": doc_id,
                    "position": len(chunks),
                    "token_count": current_tokens,
                    "target_size": target_size,
                    "complexity": self.calc_complexity(chunk_text),
                    "entity_density": self.calc_entity_density(chunk_text),
                    "adaptive": True
                })
                current_chunk_sents = []
                current_tokens = 0

            # 添加句子到当前块
            current_chunk_sents.append(sent)
            current_tokens += sent_tokens

        # 最后一块
        if current_chunk_sents:
            chunk_text = " ".join(current_chunk_sents)
            chunks.append({
                "text": chunk_text,
                "chunk_id": f"{doc_id}_chunk_{len(chunks)}",
                "doc_id": doc_id,
                "position": len(chunks),
                "token_count": current_tokens,
                "target_size": target_size or self.base_size,
                "complexity": self.calc_complexity(chunk_text),
                "entity_density": self.calc_entity_density(chunk_text),
                "adaptive": True
            })

        return chunks
```

class KTBuilder:

        chunks = [c['text'] for c in chunk_results]

        )

        return chunks, chunk2id

### 模块2：分层三元组提取器 (Layered Triple Extractor)

#### 功能说明

采用**多层递进式提取**策略，从不同角度提取关系事实：

- ✅ 显式关系：直接表达的关系
- ✅ 隐式关系：通过推理得出的关系
- ✅ Schema引导：补全遗漏的标准关系
- ✅ 跨句关系：不同句子间的隐含联系

#### 提取层级

**第1层：显式三元组提取 (Explicit Level)**

直接从文本中提取表明的事实：

```
例子：
文本："Tom Hanks directed Forrest Gump in 1994."

提取的三元组：
- (Tom Hanks, directed, Forrest Gump)
- (Tom Hanks, is_actor_in, Forrest Gump)
- (Forrest Gump, released_in, 1994)
- (Forrest Gump, genre, Drama)
```

**第2层：隐式三元组提取 (Implicit Level)**

通过推理和语言学分析提取隐含关系：

```
1. 共指关系 (Coreference)
   文本："The company was founded in 1998. It is now a tech giant."
   推导：company = it
   三元组：(company, same_as, it)

2. 因果关系 (Causality)
   文本："It was raining, so the game was cancelled."
   推导：rain → cancel game
   三元组：(rain, causes, game_cancellation)

3. 时序关系 (Temporal)
   文本："After graduation, he joined Google."
   推导：graduation → join Google
   三元组：(graduation, before, join_google)
```

**第3层：Schema引导补全 (Schema-Guided Level)**

根据本体(Ontology)schema补全遗漏的标准关系：

```
已知Schema定义：
- Person: has_birthplace, has_occupation, founded_organization
- Movie: has_director, has_actor, released_year

提取补全：
文本中有：(Tom Hanks, directed, Forrest Gump)
Schema要求：Movie应该有has_director属性
补全：(Forrest Gump, has_director, Tom Hanks)

另外检查遗漏：是否还有未提取的{Person, Movie}属性对
使用分类器预测补全
```

**第4层：跨句关系 (Cross-Sentence Level)**

提取不同句子之间的隐含关系：

```
文本：
S1: "Steve Jobs founded Apple in 1976."
S2: "He served as CEO for many years."
S3: "Under his leadership, Apple became a tech giant."

跨句三元组：
- (Steve Jobs, founded, Apple) [S1]
- (Steve Jobs, was_ceo_of, Apple) [S2 + context]
- (Steve Jobs, led_company_growth, Apple) [S3]
- (Apple, became, tech_giant) [S2+S3]  # 融合多个句子的信息
```

#### 核心代码

```python
class LayeredTripleExtractor:
    """分层三元组提取器"""

    def __init__(self, llm_client, schema, config=None):
        self.llm = llm_client
        self.schema = schema
        self.nlp = spacy.load("en_core_web_sm")
        self.embedding_model = SentenceTransformer('all-MiniLM-L6-v2')

        # 预加载关系同义词典和传递性关系列表
        self.relation_synonyms = self._load_relation_synonyms()
        self.transitive_relations = self._load_transitive_relations()

    def extract_all_layers(self, chunk_text: str) -> Dict[str, List[Dict]]:
        """提取所有层级的三元组"""

        results = {
            "explicit": [],      # L1: 显式
            "implicit": [],      # L2: 隐式
            "schema_based": [],  # L3: Schema
            "cross_sentence": [] # L4: 跨句
        }

        doc = self.nlp(chunk_text)

        # ===== 第1层：显式三元组 =====
        logger.info("Extracting explicit triples (L1)...")
        results["explicit"] = self._extract_explicit(chunk_text)

        # 提取实体列表（用于后续层）
        all_entities = set()
        for triple in results["explicit"]:
            all_entities.add(triple["head"])
            all_entities.add(triple["tail"])

        # ===== 第2层：隐式三元组 =====
        logger.info("Extracting implicit triples (L2)...")
        results["implicit"] = self._extract_implicit(doc, all_entities)

        # ===== 第3层：Schema引导补全 =====
        logger.info("Extracting schema-based triples (L3)...")
        results["schema_based"] = self._extract_schema_based(
            chunk_text, all_entities, results["explicit"]
        )

        # ===== 第4层：跨句关系 =====
        logger.info("Extracting cross-sentence triples (L4)...")
        results["cross_sentence"] = self._extract_cross_sentence(
            doc, all_entities
        )

        return results

    def _extract_explicit(self, text: str) -> List[Dict]:
        """L1: 显式三元组提取（使用LLM）"""
        prompt = f"""
Extract all explicit relations from the following text.
For each relation, provide: head (entity), relation (type), tail (entity).

Format:
head | relation | tail

Text:
{text}

Relations:
"""

        response = self.llm.call(prompt, max_tokens=300)
        triples = self._parse_llm_triples(response, confidence=0.95)

        for t in triples:
            t["type"] = "explicit"
            t["layer"] = 1

        return triples

    def _extract_implicit(self, doc, entities: Set[str]) -> List[Dict]:
        """L2: 隐式三元组提取"""
        implicit = []

        # 2.1: 共指关系
        implicit.extend(self._extract_coreference(doc))

        # 2.2: 因果关系
        implicit.extend(self._extract_causality(doc))

        # 2.3: 时序关系
        implicit.extend(self._extract_temporal(doc))

        # 2.4: 属性推断
        implicit.extend(self._extract_attributed_relations(doc, entities))

        for t in implicit:
            t["type"] = "implicit"
            t["layer"] = 2
            t["confidence"] = t.get("confidence", 0.7)

        return implicit

    def _extract_coreference(self, doc) -> List[Dict]:
        """提取共指关系"""
        # 使用spaCy的实体链接或简单的代词识别
        coref_triples = []

        pronouns = {
            "he": "male", "him": "male", "his": "male",
            "she": "female", "her": "female",
            "it": "neutral", "they": "plural", "them": "plural"
        }

        entities = [ent for ent in doc.ents]

        for sent_i, sent in enumerate(doc.sents):
            for token in sent:
                if token.pos_ == "PRON" and token.text.lower() in pronouns:
                    # 查找最近的同性别名词
                    for ent in reversed(entities):
                        if ent.sent.i <= sent_i:
                            coref_triples.append({
                                "head": str(ent),
                                "relation": "coref_with",
                                "tail": token.text,
                                "confidence": 0.8
                            })
                            break

        return coref_triples

    def _extract_causality(self, doc) -> List[Dict]:
        """提取因果关系"""
        causal_triggers = ["because", "therefore", "thus", "so", "since",
                          "as a result", "led to", "caused by"]

        causal = []

        for sent in doc.sents:
            sent_lower = sent.text.lower()

            # 检测因果触发词
            for trigger in causal_triggers:
                if trigger in sent_lower:
                    # 使用LLM解析因果关系
                    triple = self._parse_causal_sentence(sent.text)
                    if triple:
                        triple["confidence"] = 0.75
                        causal.append(triple)
                    break

        return causal

    def _extract_temporal(self, doc) -> List[Dict]:
        """提取时序关系"""
        temporal_triggers = ["before", "after", "then", "next", "later",
                           "previously", "subsequently", "meanwhile"]

        temporal = []

        for sent in doc.sents:
            sent_lower = sent.text.lower()

            for trigger in temporal_triggers:
                if trigger in sent_lower:
                    triple = self._parse_temporal_sentence(sent.text)
                    if triple:
                        triple["confidence"] = 0.75
                        temporal.append(triple)
                    break

        return temporal

    def _extract_attributed_relations(self, doc,
                                     entities: Set[str]) -> List[Dict]:
        """提取属性推断关系"""
        attributed = []

        # 例：识别"the largest company"中的"largest"属性
        for sent in doc.sents:
            for token in sent:
                # 查找形容词修饰的名词
                if token.pos_ == "ADJ":
                    for child in sent:
                        if child.head == token and child.pos_ in ["NOUN", "PROPN"]:
                            attributed.append({
                                "head": str(child),
                                "relation": "has_attribute",
                                "tail": token.text,
                                "confidence": 0.65
                            })

        return attributed

    def _extract_schema_based(self, text: str, entities: Set[str],
                             explicit_triples: List[Dict]) -> List[Dict]:
        """L3: Schema引导的关系补全"""
        schema_based = []

        # 构建已提取关系的集合
        extracted_pairs = {
            (t["head"], t["relation"], t["tail"])
            for t in explicit_triples
        }

        # 遍历Schema中定义的所有关系类型
        for rel_schema in self.schema.get("relations", []):
            rel_type = rel_schema["name"]
            domain = rel_schema.get("domain", "")
            range_ = rel_schema.get("range", "")

            # 对每个可能的实体对
            for head in entities:
                for tail in entities:
                    if head == tail:
                        continue

                    triple_key = (head, rel_type, tail)

                    # 如果此关系尚未被提取
                    if triple_key not in extracted_pairs:
                        # 使用分类器判断是否应该有此关系
                        score = self._relation_classifier(
                            text, head, tail, rel_type
                        )

                        if score > 0.5:  # 阈值
                            schema_based.append({
                                "head": head,
                                "relation": rel_type,
                                "tail": tail,
                                "confidence": score,
                                "type": "schema_guided"
                            })

        return schema_based

    def _extract_cross_sentence(self, doc,
                               entities: Set[str]) -> List[Dict]:
        """L4: 跨句关系提取"""
        cross_sent = []
        sentences = list(doc.sents)

        # 滑动窗口：检查連續句子
        for i in range(len(sentences) - 1):
            s1, s2 = sentences[i], sentences[i+1]

            # 提取两个句子中的实体
            s1_ents = [e.text for e in s1.ents if e.text in entities]
            s2_ents = [e.text for e in s2.ents if e.text in entities]

            # 如果有共享实体或相关实体
            if s1_ents and s2_ents:
                combined = s1.text + " " + s2.text

                # 使用LLM提取跨句关系
                triples = self._extract_with_context_llm(
                    combined, s1_ents + s2_ents
                )

                for t in triples:
                    t["type"] = "cross_sentence"
                    t["confidence"] = t.get("confidence", 0.7)
                    cross_sent.append(t)

        return cross_sent
```

### 模块3：双重冗余剪枝器 (Dual-Redundancy Pruner)

#### 功能说明

移除**重复和冗余的三元组**，保持知识图谱的精炼性：

1. **相似度冗余**：语义相同的三元组
2. **传递性冗余**：可以通过推理得出的三元组

#### 冗余判定规则

**相似度冗余 (Similarity-Based Redundancy)**

```
规则：两个三元组如果满足以下条件认为冗余：

1. 实体匹配度高 (entity match)
   - head1 ≈ head2 (字等或语义相似)
   - tail1 ≈ tail2

2. 关系同义度高 (relation synonymy)
   - relation1 ≈ relation2 (同义词或反义)

例子：
- (Beijing, located_in, China)
  vs
  (Beijing, in, China)
  → redundant (区别仅在关系表述)

- (A, parent_of, B)
  vs
  (B, child_of, A)
  → redundant (相同语义，相反方向)
```

**传递性冗余 (Transitivity-Based Redundancy)**

```
规则：如果满足以下条件认为冗余：

存在链式关系：
  (A, R, B) ∧ (B, R, C) ⟹ (A, R, C)

若R具有传递性，则(A, R, C)冗余

例子：
- (Europe, part_of, World)
  (France, part_of, Europe)
  Therefore: (France, part_of, World) 冗余

传递性关系列表：
- part_of, ancestor_of, located_in, greater_than, ...
```

#### 核心代码

```python
class DualRedundancyPruner:
    """双重冗余剪枝器"""

    def __init__(self, llm=None, similarity_threshold=0.85):
        self.llm = llm
        self.threshold = similarity_threshold
        self.embed_model = SentenceTransformer('all-MiniLM-L6-v2')

        # 预定义的冗余规则
        self.transitive_relations = {
            "part_of", "located_in", "ancestor_of", "parent_of",
            "contains", "greater_than", "precedes"
        }

        self.relation_synonyms = self._load_synonyms()
        self.inverse_relations = self._load_inverse_relations()

    def prune_all(self, triples: List[Dict],
                  knowledge_graph: nx.DiGraph = None) -> List[Dict]:
        """执行双重冗余剪枝"""

        logger.info(f"Starting dual-redundancy pruning on {len(triples)} triples")

        # 步骤1：相似度冗余去除
        logger.info("  Step 1: Detecting similarity-based redundancy...")
        triples_after_sim = self._prune_similarity_redundancy(triples)
        sim_removed = len(triples) - len(triples_after_sim)
        logger.info(f"    Removed {sim_removed} redundant triples by similarity")

        # 步骤2：传递性冗余去除
        if knowledge_graph is not None:
            logger.info("  Step 2: Detecting transitivity-based redundancy...")
            triples_after_trans = self._prune_transitivity_redundancy(
                triples_after_sim, knowledge_graph
            )
            trans_removed = len(triples_after_sim) - len(triples_after_trans)
            logger.info(f"    Removed {trans_removed} transitive redundancy triples")
        else:
            triples_after_trans = triples_after_sim
            logger.warning("    Skipping transitivity check (no graph provided)")

        logger.info(f"Final count: {len(triples_after_trans)} triples "
                   f"(removed {len(triples) - len(triples_after_trans)} total)")

        return triples_after_trans

    def _prune_similarity_redundancy(self,
                                    triples: List[Dict]) -> List[Dict]:
        """相似度冗余去除"""

        # 步骤1：聚类相似三元组
        redundancy_clusters = self._cluster_similar_triples(triples)

        # 步骤2：每个簇中选择最佳代表
        indices_to_keep = set(range(len(triples)))

        for cluster in redundancy_clusters:
            if len(cluster) <= 1:
                continue

            # 评分并选择最佳
            best_idx = self._select_best_representative(
                triples, cluster
            )

            # 移除其他
            for idx in cluster:
                if idx != best_idx:
                    indices_to_keep.discard(idx)

        # 步骤3：返回保留的三元组
        return [triples[i] for i in sorted(indices_to_keep)]

    def _cluster_similar_triples(self, triples: List[Dict]) -> List[Set[int]]:
        """聚类相似的三元组"""

        n = len(triples)
        clustered = [set() for _ in range(n)]

        for i in range(n):
            for j in range(i + 1, n):
                similarity = self._compute_triple_similarity(
                    triples[i], triples[j]
                )

                if similarity >= self.threshold:
                    # 标记为相似
                    clustered[i].add(j)
                    clustered[j].add(i)

        # 合并连通的簇
        merged_clusters = []
        visited = set()

        for i in range(n):
            if i not in visited:
                cluster = self._dfs_cluster(i, clustered, visited)
                if cluster:
                    merged_clusters.append(cluster)

        return merged_clusters

    def _compute_triple_similarity(self, t1: Dict, t2: Dict) -> float:
        """计算两个三元组的相似度"""

        # 方法1：嵌入相似度 (embedding)
        text1 = f"{t1['head']} {t1['relation']} {t1['tail']}"
        text2 = f"{t2['head']} {t2['relation']} {t2['tail']}"

        emb1 = self.embed_model.encode([text1])
        emb2 = self.embed_model.encode([text2])

        from sklearn.metrics.pairwise import cosine_similarity
        embed_sim = cosine_similarity(emb1, emb2)[0][0]

        # 方法2：成分相似度 (component)
        head_sim = self._entity_similarity(t1['head'], t2['head'])
        rel_sim = self._relation_similarity(t1['relation'], t2['relation'])
        tail_sim = self._entity_similarity(t1['tail'], t2['tail'])

        comp_sim = (head_sim + rel_sim + tail_sim) / 3.0

        # 综合 (weighted combination)
        final_sim = 0.5 * embed_sim + 0.5 * comp_sim

        return final_sim

    def _entity_similarity(self, e1: str, e2: str) -> float:
        """实体相似度"""
        # 完全相同
        if e1.lower() == e2.lower():
            return 1.0

        # 子串包含
        e1_lower, e2_lower = e1.lower(), e2.lower()
        if e1_lower in e2_lower or e2_lower in e1_lower:
            return 0.85

        # 编辑距离
        from difflib import SequenceMatcher
        seq_ratio = SequenceMatcher(None, e1_lower, e2_lower).ratio()

        # 嵌入相似度
        emb1 = self.embed_model.encode([e1])
        emb2 = self.embed_model.encode([e2])
        from sklearn.metrics.pairwise import cosine_similarity
        embed_sim = cosine_similarity(emb1, emb2)[0][0]

        return 0.3 * seq_ratio + 0.7 * embed_sim

    def _relation_similarity(self, r1: str, r2: str) -> float:
        """关系相似度"""
        # 完全相同
        if r1.lower() == r2.lower():
            return 1.0

        # 检查同义词
        for synset in self.relation_synonyms.values():
            r1_in = r1.lower() in synset
            r2_in = r2.lower() in synset
            if r1_in and r2_in:
                return 0.95

        # 检查反向关系（可视为相同但方向相反）
        inverse_key = self._find_inverse_relation(r1)
        if inverse_key and r2.lower() == inverse_key:
            return 0.9  # 略低于同向

        # 嵌入相似度
        emb1 = self.embed_model.encode([r1])
        emb2 = self.embed_model.encode([r2])
        from sklearn.metrics.pairwise import cosine_similarity
        embed_sim = cosine_similarity(emb1, emb2)[0][0]

        return embed_sim

    def _select_best_representative(self, triples: List[Dict],
                                   cluster: Set[int]) -> int:
        """从冗余簇中选择最佳代表"""

        best_score = -1
        best_idx = list(cluster)[0]

        for idx in cluster:
            t = triples[idx]
            score = 0.0

            # 因素1：置信度 (30%)
            confidence = t.get("confidence", 0.5)
            score += confidence * 0.3

            # 因素2：类型优先级 (40%)
            type_priority = {
                "explicit": 1.0,
                "schema_based": 0.75,
                "cross_sentence": 0.7,
                "implicit": 0.5
            }
            type_score = type_priority.get(t.get("type", "explicit"), 0.5)
            score += type_score * 0.4

            # 因素3：信息完整度 (30%)
            info_score = min(
                (len(t["head"]) + len(t["relation"]) + len(t["tail"])) / 100.0,
                1.0
            )
            score += info_score * 0.3

            if score > best_score:
                best_score = score
                best_idx = idx

        return best_idx

    def _prune_transitivity_redundancy(self, triples: List[Dict],
                                      graph: nx.DiGraph) -> List[Dict]:
        """传递性冗余去除"""

        indices_to_remove = set()

        for i, triple in enumerate(triples):
            head = triple["head"]
            tail = triple["tail"]
            relation = triple["relation"]

            # 检查是否为传递性关系
            if relation not in self.transitive_relations:
                continue

            # 检查是否存在传递路径
            if not graph.has_node(head) or not graph.has_node(tail):
                continue

            try:
                # 查找所有从head到tail的简单路径（长度>1）
                paths = list(nx.all_simple_paths(
                    graph, head, tail, cutoff=3
                ))

                # 如果存在更长的路径，说明直接边可能冗余
                for path in paths:
                    if len(path) > 2:  # 存在间接路径
                        # 检查间接路径上的关系
                        all_intermediate_same_rel = True
                        for j in range(len(path) - 1):
                            edge_data = graph.edges[path[j], path[j+1]]
                            if edge_data.get("relation") != relation:
                                all_intermediate_same_rel = False
                                break

                        # 如果中间路径都是相同关系，则直接边冗余
                        if all_intermediate_same_rel:
                            indices_to_remove.add(i)
                            break

            except nx.NetworkXNoPath:
                pass  # 没有路径，不冗余

        # 返回去除冗余的三元组
        return [t for i, t in enumerate(triples) if i not in indices_to_remove]
```

class DancerExperiment:
    def __init__(self):
        self.dataset = HotpotQADataset("data/hotpotqa")

    def run_ablation_study(self):
        """运行消融实验"""

        configs = {
            "baseline": {
                "use_deker": False,
                "use_dynamic_granularity": False,
                "use_layered_extraction": False,
                "use_redundancy_pruning": False
            },
            "dynamic_only": {
                "use_deker": True,
                "use_dynamic_granularity": True,
                "use_layered_extraction": False,
                "use_redundancy_pruning": False
            },
            "extraction_only": {
                "use_deker": True,
                "use_dynamic_granularity": False,
                "use_layered_extraction": True,
                "use_redundancy_pruning": False
            },
            "deker_full": {
                "use_deker": True,
                "use_dynamic_granularity": True,
                "use_layered_extraction": True,
                "use_redundancy_pruning": True
            }
        }

        results = {}

        for config_name, config in configs.items():
            logger.info(f"Running experiment: {config_name}")
            result = self._run_single_experiment(config)
            results[config_name] = result

        return self._compare_results(results)

    def _run_single_experiment(self, config) -> Dict:
        """运行单个配置的实验"""

        # 创建KTBuilder
        kt_builder = KTBuilder(config)

        # 构建知识图谱
        graphs = {}
        for doc_id, doc in self.dataset.documents.items():
            graph = kt_builder.build_for_document(doc)
            graphs[doc_id] = graph

        # 评估
        eval_results = self._evaluate(graphs)

        return eval_results

    def _evaluate(self, graphs: Dict) -> Dict:
        """评估知识图谱质量"""

        metrics = {
            "coverage": [],         # 知识覆盖率
            "precision": [],        # 提取精准率
            "redundancy_rate": [],  # 冗余率
            "qa_accuracy": []       # QA准确率
        }

        for doc_id, graph in graphs.items():
            # 针对每个文档计算指标
            coverage = self._calc_coverage(doc_id, graph)
            precision = self._calc_precision(doc_id, graph)
            redundancy = self._calc_redundancy_rate(graph)
            qa_acc = self._calc_qa_accuracy(doc_id, graph)

            metrics["coverage"].append(coverage)
            metrics["precision"].append(precision)
            metrics["redundancy_rate"].append(redundancy)
            metrics["qa_accuracy"].append(qa_acc)

        # 平均值
        return {
            "coverage": np.mean(metrics["coverage"]),
            "precision": np.mean(metrics["precision"]),
            "redundancy_rate": np.mean(metrics["redundancy_rate"]),
            "qa_accuracy": np.mean(metrics["qa_accuracy"])
        }
